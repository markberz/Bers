# Mark Berio — Personal Portfolio

This is my Personal website to show interests in web development, embedded systems, and technical support. Browse selected projects, experience, technologies, and credentials, or get in touch about an opportunity or collaboration.

## Portfolio features

- Project gallery featuring web and embedded-systems work
- Experience, skills, certifications, and credentials
- Contact options for email, LinkedIn, and scheduling a meeting
- Dark and light themes
- Responsive interface built with React

## Built with

- React
- Vite
- JavaScript
- Tailwind CSS and Bootstrap

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/markberz/Bers.git
cd Bers
npm install
npm run dev
```

## Push changes to GitHub

From the project directory, check which files have changed and stage only the files you want to publish:

```bash
git status
git add <file-or-folder>
git commit -m "Describe your changes"
git push origin main
```

Replace `<file-or-folder>` with the path to a changed file or folder. If you are working on a different branch, replace `main` with that branch's name. For a new branch's first push, use `git push -u origin <branch-name>`; after that, `git push` is sufficient. GitHub may ask you to authenticate using your configured Git credentials or browser.
